Methodology

About the Predictive Model

The prediction engine runs entirely within this page using a compressed random forest. No data is transmitted to any server during prediction.

Algorithm
Random Forest Regressor — 100 decision trees
Target Variable
Mental health score (continuous, 1–10)
Feature Engineering
Study hours log-transformed; continuous variables standardised; stress encoded ordinally (Low → Very High); categorical fields one-hot encoded; countries outside the top nine grouped as "Other"
In-sample Fit
R² = 0.95 · Mean Absolute Error = 0.19 points
In-browser Version
40 of 100 trees; within 0.04 points of the full model on average

AI-Powered Support

Mental Health Support Assistant

Powered by a large language model with live web search capability. Raise any concern regarding sleep, anxiety, academic pressure, or social media balance. The assistant retrieves current, evidence-based information and cites its sources.

Setup required: Start the server with python -m uvicorn rag_engine:app --host 127.0.0.1 --port 8000 then open http://127.0.0.1:8000. Add your GROQ_API_KEY to a .env file (see .env.example).
Privacy: Your messages are processed via the Groq API. Web searches use DuckDuckGo. Location data, if shared, is transmitted only to OpenStreetMap. No data is stored on disk.
